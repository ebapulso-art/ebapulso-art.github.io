\

Diseñamos para dar forma a lo que querés comunicar. \

\

PULSO es un espacio de diseño enfocado en identidad visual, comunicación y experiencias digitales. \

\

Creatividad \

04 — Proceso \

\

Del primer \pulso\ al resultado. \

\
\
\
\ 01 \ \

Escuchamos \

\

Conocemos tu idea, tus necesidades y lo que querés transmitir. \

\
\
\ 02 \ \

Investigamos \

\

Analizamos el contexto, el público y las referencias del proyecto. \

\
\
\ 03 \ \

Diseñamos \

\

Convertimos la idea en una propuesta visual concreta. \

\
\
\ 04 \ \

Ajustamos \

\

Revisamos detalles y perfeccionamos el resultado junto con vos. \

\
\
\ 05 \ \

Entregamos \

\

Dejamos todo preparado para que puedas usar tu proyecto. \

\
